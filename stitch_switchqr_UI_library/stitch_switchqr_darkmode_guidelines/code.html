Dark Mode Guidelines

A comprehensive guide to the SwitchQR dark aesthetic, accessibility standards, and component behavior in low-light environments.

Section 1: Core Colors

The foundation of our dark mode is built on deep navy and slate tones to provide depth and reduce eye strain.

#0F172A

Background

Deep navy base layer for the main canvas.

#1E293B
